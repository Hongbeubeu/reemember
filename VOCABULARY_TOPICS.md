# Vocabulary Topics

Danh sách chủ đề từ vựng để agent sinh từ mới và import vào app.

**Quy ước:**
- Đánh dấu `[x]` sau khi đã sinh từ và import thành công.
- Mỗi topic sinh **20–30 từ**, ưu tiên từ thông dụng, có ví dụ thực tế.
- Format import: JSON bundle với `collection` và `topic` khớp chính xác tên bên dưới.
- Mỗi từ cần: `word`, `definitions` (có `pos`), `examples` (1–3 câu), `synonyms`, `antonyms` (nếu có).
